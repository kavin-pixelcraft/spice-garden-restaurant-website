# Spice Garden – Restaurant Website

A modern, responsive restaurant website built using HTML, CSS, and JavaScript.

## Features
- Responsive design for desktop, tablet, and mobile
- Mobile navigation menu
- Interactive food menu filters
- Restaurant information and customer reviews
- Reservation enquiry form with frontend validation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Live Demo
https://spice-garden-restaurant-website-demo.netlify.app

## Note
This is a frontend demo project. The reservation form currently demonstrates client-side validation and does not send or store actual bookings.
